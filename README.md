# Study Abroad Frontend Assessment

## Tech Stack
- Next.js 14 (App Router)
- Material-UI 5
- Zustand (state + caching)
- DummyJSON API

## Setup
 - npm install
 - npm run dev

## Features
- ✅ Auth with NextAuth + Zustand
- ✅ Protected dashboard routes
- ✅ Users: pagination, search, details
- ✅ Products: pagination, search, category filter, grid
- ✅ Responsive MUI design
- ✅ Client-side caching (Zustand persist)
- ✅ Performance: memoization, debouncing

## Why Zustand?
Simple 1KB store, built-in async/persist/devtools, no Context re-renders [web:2]
